# Security policy

REDACTED is an in-progress fork of Ramble. Do not treat the current repository as a production-ready secure messenger.

## Reporting a vulnerability
Please do not publish exploit details or secrets in public issues. Contact the repository owner privately using GitHub's security advisory reporting feature when enabled.

## Before publishing builds
- Check dependencies and upstream notices.
- Keep credentials and signing keys outside Git.
- Verify encryption, message routing and reconnection behavior on actual devices.
- Do not claim end-to-end security without an independent review.
